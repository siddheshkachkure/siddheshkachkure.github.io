# Siddhesh Kachkure — AI × HPC Infrastructure Portfolio

Responsive, dependency-free engineering portfolio for AI/HPC compute, high-speed fabrics, parallel filesystems, enterprise storage, workload workflows and production operations, using a dark cyberpunk visual system.

- Custom SVG system overview and animated logical data paths.
- Interactive GPU-to-GPU, GPU-to-storage and GPUDirect Storage workflow lab.
- Exploded logical GPU-server cutaway and parallel-storage stack.
- Skill-domain browser, detailed career timeline, projects, education and certifications.
- Keyboard focus states, mobile-responsive layouts, reduced-motion support, cache-busted assets and a static architecture fallback if JavaScript initialization fails.

Static HTML, CSS and vanilla JavaScript hosted with GitHub Pages. The visual design uses local/system font fallbacks and does not require an external font CDN. Diagrams are explanatory models, not packet captures or vendor-specific physical wiring. GDS support must be validated on the target platform. Certification dates reflect the supplied résumé; check current status before publication.
